第一次连接

  1. Quest 开启开发者模式，USB 连接电脑，并在头显内允许 USB 调试。
  2. Ubuntu 电脑运行 ./usb.sh，或执行 adb reverse tcp:8765 tcp:8765。
  3. 独立模式在电脑页选择「Quest USB」；联合模式由终端自动选择。在 Quest 浏览器打开 ，点击「进入透视并采集」。若透视不支持，可选 VR 采集。
  4. 佩戴头显并让相机朝向双手。在电脑操作台确认双手柄是真实 6DoF 追踪后，再校准或由联合终端自动校准。校准时机械臂保持不动。
  5. 独立手柄模式可用右手 A/B 校准/暂停；Quest + Wuji 联合模式由电脑终端自动校准和开始，空格暂停或继续。网页「暂停双臂」可立即保持当前位置。

头显挂在脖子上、连接件挡住手柄、强光照射都会增加丢踪。联合模式下短时光学丢踪会保持姿态；其他采集故障会暂停。请查看电脑终端提示。
